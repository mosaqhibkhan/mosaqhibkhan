### 2. Personalized Workout & Diet Recommendation System

A full-stack application integrating machine learning to generate workout and diet recommendations based on fitness goals and experience levels.

**Key Contributions**

- Designed a three-service architecture using React, Node.js/Express, and Python/Flask.
- Developed a reproducible machine learning pipeline using Scikit-learn.
- Generated and validated a synthetic dataset containing 2,000 records, removing 100 exact duplicates.
- Evaluated nine candidate models using stratified 5-fold cross-validation.
- Selected an interpretable Decision Tree Classifier based on model evaluation and feature relevance.
- Implemented a Scikit-learn Pipeline with OneHotEncoder for categorical feature processing.
- Integrated the Flask ML service with the Express backend through HTTP APIs.
- Implemented multi-layer input validation, model schema checks, request timeouts, and structured error handling.
- Developed nine 7-day workout templates and three goal-based diet templates.
- Implemented 98 automated tests across Python and Node.js.
- Verified reproducibility through byte-identical dataset, model, and evaluation artifact generation.

**Technology Stack:** React 19, Vite, Tailwind CSS, Node.js, Express 5, Python, Flask, Scikit-learn, Pandas, NumPy, Joblib.
