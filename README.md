### 2. Personalized Workout & Diet Recommendation System

A full-stack application that generates 7-day workout schedules and goal-based diet recommendations using machine learning and rule-based logic.

**Key Contributions**
- Designed a three-service architecture using React, Node.js/Express, and Python/Flask.
- Developed a reproducible machine learning pipeline using Scikit-learn.
- Generated and validated a synthetic dataset containing 2,000 records.
- Evaluated nine candidate classification models using stratified 5-fold cross-validation.
- Selected a Decision Tree Classifier for workout plan classification.
- Integrated the Flask ML service with the Express backend through HTTP APIs.
- Implemented multi-layer input validation, model schema checks, request timeouts, and structured error handling.
- Developed nine 7-day workout templates and three goal-based diet templates.
- Implemented 98 automated tests across Python and Node.js.

**Tech Stack:** React, Vite, Tailwind CSS, Node.js, Express.js, Python, Flask, Scikit-learn, Pandas, NumPy.
